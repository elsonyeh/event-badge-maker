# 🪪 名牌產生器（Google Apps Script）

用 Google 試算表管理名單、用網頁調整名牌版面、一鍵把名單套進背景圖片並輸出成 PNG。
背景圖片、試算表都可以換，換一次活動只要「連結新試算表 + 換背景圖片」兩個步驟。

---

## 這個工具在做什麼

- **背景圖片沒有解析度上限**：圖片存在你的 Google Drive，輸出時是照原始像素尺寸畫，不會被壓縮。
- **名單來源就是 Google 試算表**：你可以直接在試算表裡編輯，也可以在本工具的網頁介面新增/編輯/批次貼上/
  上傳本機 Excel 或 CSV 檔案。
- **既有資料不用重打**：連結一份已經有名單的試算表時，工具會自動偵測裡面的分頁，一鍵「採用」就能沿用
  它目前的欄位，不用重新輸入一次。
- **版面用拖曳調整**：在網頁上把「姓名」「編號」「組別」…等欄位拖到背景上想要的位置，字級、顏色、字型、對齊都能調。
- **只產生「新的」名牌**：每一列名單都有「產生狀態」，已經產生過的不會重複做，新增的名單一鍵就能補產生。
- **一個試算表可以放多種名牌**：例如「學員 / 工作人員 / 講師貴賓」各自有自己的背景圖、版面、名單分頁。
- **也可以同時連結好幾份試算表**：類別分散在不同試算表也沒關係，全部連起來，類別清單會自動彙總、
  標明每個類別來自哪一份。
- **每個瀏覽器分頁各自獨立、有紀錄可回復**：連結了哪些試算表記在瀏覽器分頁自己身上，開好幾個分頁
  互不影響；「最近使用過」清單會記住連過的試算表，就算分頁關掉、換電腦，資料本身也都還在 Drive 裡，
  隨時能重新連回來。
- **可以匯出成排版好的 PDF**：紙張大小（A4／Letter／自訂）、一頁排幾行幾列、間距邊界都能設定，適合
  直接送印刷廠或用印表機批次列印。
- **換活動 = 換試算表連結**：每個試算表都是獨立、可攜帶的一份「活動設定」，複製一份舊的當範本，或建立全新的都可以。

### 架構（給有興趣的人）

```
Google 試算表（每個活動一份）
 ├─ 設定 分頁         ← 每個名牌類別一列：背景圖片ID、寬高、輸出資料夾、版面設定(JSON)
 ├─ 學員 分頁          ← 名單資料，第一列是欄位標題，工具會自動補上「產生狀態／產生時間／圖片連結」
 ├─ 工作人員 分頁
 └─ 講師貴賓 分頁

Apps Script 網頁應用程式（獨立專案，不綁定特定試算表）
 ├─ Code.gs           ← 讀寫試算表 / Drive，只做這件事
 ├─ Index.html         ← 頁面框架
 ├─ Stylesheet.html    ← 樣式
 └─ JavaScript.html    ← 版面編輯器、名單管理、圖片合成（背景+文字 → PNG）都在瀏覽器端用 <canvas> 完成
```

圖片合成故意放在瀏覽器端（不是伺服器端）：這樣單張圖片沒有解析度限制，而且大量產生名牌時不會撞到
Apps Script 單次執行 6 分鐘的時間上限（每張圖是各自獨立的一次存檔請求）。

## 一、部署步驟

### 1. 開啟 Apps Script 專案

你已經有一個空的 Apps Script 專案，直接打開它：
https://script.google.com/d/1vBCdy8l9TJ8wRcwg5GV1TOqMnpWqHQuNz3WkM8uOhVo1S-aqiyCvjAhc/edit

（如果之後想另外建一個新的，就到 https://script.google.com/ 點「新專案」）

### 2. 建立 4 個檔案並貼上程式碼

專案預設會有一個 `Code.gs`。你總共需要 **4 個檔案**，對應本資料夾 `apps-script/` 底下的 4 個檔案：

| 要建立的檔案 | 類型 | 在編輯器建立時要輸入的名稱 | 本機對應檔案 |
|---|---|---|---|
| `Code.gs` | 指令碼（已存在，直接用） | — | `apps-script/Code.gs` |
| `Index.html` | HTML | `Index` | `apps-script/Index.html` |
| `Stylesheet.html` | HTML | `Stylesheet` | `apps-script/Stylesheet.html` |
| `JavaScript.html` | HTML | `JavaScript` | `apps-script/JavaScript.html` |

> ⚠️ **檔名一定要完全一致**（大小寫也要對），因為程式裡是用檔名互相引用的（例如 `include('Stylesheet')`）。
> 在 Apps Script 編輯器新增 HTML 檔案時，它會自動幫你加上 `.html`，所以「命名」的框框裡**只要打
> `Index`、`Stylesheet`、`JavaScript`，不要自己再打副檔名**。

步驟：

1. 左側檔案列表點 `Code.gs`，把裡面預設的內容**全部刪除**，貼上本機 `apps-script/Code.gs` 的全部內容。
2. 點檔案列表旁邊的「＋」→「指令碼」是 `.gs`，這裡選「**HTML**」→ 輸入 `Index` → Enter。
3. 把預設產生的內容全部刪除，貼上本機 `apps-script/Index.html` 的全部內容。
4. 重複步驟 2-3，分別建立 `Stylesheet`、`JavaScript` 兩個 HTML 檔案，貼上對應內容。
5. 上方工具列點「💾 儲存專案」（或 Ctrl/Cmd + S）。

### 3. 部署為網頁應用程式

1. 右上角「部署」→「新增部署作業」。
2. 齒輪圖示選類型「**網頁應用程式**」。
3. 設定：
   - **說明**：隨意，例如「v1」。
   - **執行身分**：**我**（一定要選這個，這樣不管誰打開網頁，讀寫試算表/Drive 都是用你的權限執行，訪客不需要另外授權）。
   - **誰可以存取**：
     - 只有你自己用 → 選「**只有我自己**」。
     - 現場報到櫃檯多人共用、但都要有 Google 帳號 → 選「**知道連結的使用者**」。
     - 現場用平板/共用電腦、不想每次登入 Google → 選「**所有人**」。
       （這個選項任何人只要有網址就能新增/產生名牌，請不要把網址公開貼出去，當成一組密碼保管）
4. 點「部署」。**第一次部署會跳出 Google 的授權畫面**：
   - 選你自己的帳號。
   - 出現「Google 尚未驗證這個應用程式」的警告 → 這是正常的，因為這是你自己寫的私人工具，不是上架
     的公開應用程式。點左下角「**進階**」→「**前往（不安全）**」→「允許」。
   - 這個畫面只有「程式碼有更動並產生新版部署」時才會需要重新確認一次，平常使用不會再看到。
5. 部署完成後會給你一個網址，長得像：
   `https://script.google.com/macros/s/AKfycb.../exec`
   把它加入書籤 —— **這就是之後大家操作名牌工具用的網址**。

> 📌 之後如果你修改了程式碼想更新，要到「部署」→「管理部署作業」→ 點編輯（鉛筆圖示）→
> 版本選「**新版本**」→ 部署。這樣網址不會變，但會套用最新程式碼。

## 二、建立第一個活動試算表

打開剛剛部署的網址，會看到「① 活動設定」頁籤。依你的情況選一種：

### 情況 A：從零開始，還沒有任何名單

點「**建立新的活動試算表**」，輸入名稱（例如 `2026基因體流行病學研習營`）。這會建立一份新的 Google
試算表並自動連結好，**同時直接幫你建立好「學員／工作人員／講師貴賓」三個類別**，欄位分別是
`身分,姓名,組別` / `姓名` / `單位,職稱,姓名`——跟 `sample-data/` 裡的範例名單完全對應，不用再手動輸入
一次欄位名稱，接著可以直接跳到「三、版面編輯」上傳背景圖。

如果這三種類別跟你的活動不符，到「名牌類別」區塊下方「自訂新增類別」照你的需求輸入即可；用不到的
類別留著不理會也沒關係。

### 情況 B：已經有一份 Google 試算表，裡面已經有名單資料

把試算表網址貼到「貼上 Google 試算表網址」欄位、按「連結」。連結後，如果偵測到裡面有還沒被工具
認識的分頁（例如你自己原本就在用的報名表），會出現「**偵測到這份試算表裡還有其他分頁**」區塊，列出
每個分頁目前的欄位標題和筆數，按「**採用為類別**」就會直接用該分頁目前的標題列當欄位——**不用重新
輸入欄位、也不用搬動資料**，工具只是「認養」這個分頁、幫它補上系統要用的「產生狀態／產生時間／
圖片連結」三欄。

如果你的資料是放在本機的 Excel 檔（還沒上傳到 Google 試算表），可以連結一份新的空白試算表後，到
「④ 名單管理」用「📄 上傳 Excel / CSV 檔案」直接匯入（見下方「四、名單管理」）。

### 想補齊範本類別／既有分頁都用過了

「名牌類別」區塊下方隨時都有「🚀 快速建立範本類別」按鈕，會補上「學員／工作人員／講師貴賓」裡**還
沒建立**的類別，已存在的不會被覆蓋、也不會重複建立。

## 三、版面編輯：上傳背景、拖曳文字位置

切到「② 版面編輯」頁籤，上方選你要設定的類別（例如「學員」）。

1. 點「⬆️ 上傳 / 更換背景圖片」，選一張圖片。
   - 可以直接用參考資料夾裡的 `名牌底圖-學員.png`（學員用）、`名牌底圖-工作人員.png`（工作人員用）、
     `名牌底圖-老師與貴賓.png`（講師貴賓用）先測試看看。
   - 圖片大小沒有硬性限制，但建議單張控制在 20MB 以內，上傳跟產生時比較順暢。
   - **第一次上傳背景、畫布上還沒有任何欄位時，工具會自動把這個類別的欄位排好一組通用起始位置**
     （由上而下依欄位在標題列的順序平均分布在畫布中段，欄位名稱含「姓名/name」的會自動放大、加粗
     當作主要欄位），不用每個欄位都自己拖。接下來只要微調位置、字級即可，記得存檔。
   - 如果後來又新增了欄位，或想重新套用這組通用起始位置，隨時可以按工具列上的「🧩 自動排版未放置的
     欄位」——已經手動調整過的欄位不會被動到，只會補上還沒放置的。
   - 工具列的「⬇️ 下載空白背景」可以把目前這個類別的背景原始檔案（沒有套任何文字）下載下來，
     適合要另外印一批空白名牌現場手寫、或給印刷廠對版用。
2. 左側「可用欄位」會列出這個分頁的欄位（例如 身分／姓名／組別）。也可以把想要的欄位**拖到畫布上**
   放開，手動指定要放的位置，就會出現一個文字方塊，內容是這個欄位第一筆資料當作預覽（還沒有資料的話
   會顯示 `[欄位名稱]`）。
3. 點選畫布上的文字方塊，右側「欄位樣式」可以調：
   - **字級**：以背景圖原始解析度為準的像素值。文字太長時工具會自動縮小字級、必要時自動換行，這個
     字級是「最大字級」的意思。
   - **顏色 / 字型 / 粗體 / 對齊**。
   - **最大寬度 (%)**：文字超過這個寬度就會觸發自動縮小 / 換行，避免長名字爆版。
   - **X / Y (%)**：也可以直接打數字微調位置，不一定要用拖的。
   - **⬌ 水平置中 / ⬍ 垂直置中**：一鍵把選取的欄位移到畫布正中間（X=50% 或 Y=50%），不用自己算座標。
4. 畫布正上方有「↩️ 上一步 / ↪️ 下一步 / 💾 儲存版面設定」——拖曳、調整樣式、增刪欄位都會記一筆，
   調整壞了隨時可以上一步復原。「儲存版面設定」平常是淺色不能點的，**有還沒存檔的變更時才會變深色可以點**，
   離開頁籤或切換類別前如果還有沒存的變更也會提示你是否要放棄。

> 💡 提示：可以先在「③ 名單管理」貼一兩筆真實資料，再回到版面編輯，這樣拖曳時看到的預覽文字就是
> 真實姓名的長度，比較準。

## 四、名單管理：匯入、新增、編輯

切到「③ 名單管理」頁籤。有三種方式把名單放進來，效果一樣（都是同一個 Google 試算表分頁）：

### 方式 A：直接在 Google 試算表編輯（最適合大量匯入）

1. 開啟目前連結的那份試算表（頂部藍色標題列有連結）。
2. 找到對應類別的分頁（例如「學員」）。
3. 用「檔案 → 匯入 → 上傳」把 CSV 匯入，或直接複製貼上——**只要貼在正確的欄位標題下面就好，不要
   動到「產生狀態／產生時間／圖片連結」這三欄**。
4. 本資料夾 `sample-data/` 裡準備了三份可以直接測試的範例名單（從你參考資料夾的 `名牌資訊v2.xlsx`
   整理出來的真實資料）：
   - `學員_名單_範例.csv`（139 筆，欄位：身分,姓名,組別）
   - `工作人員_名單_範例.csv`（13 筆，欄位：姓名）
   - `講師貴賓_名單_範例.csv`（3 筆示範列，欄位：單位,職稱,姓名 —— 原始名冊裡這部分格式不統一，
     這裡只整理出可以確定對應關係的幾筆當範本，正式使用時請自行補齊）

### 方式 B：在網頁上「新增一筆」

名單管理頁籤下方「新增一筆」會依目前類別的欄位自動出現對應的輸入框，填完按「新增」，馬上就會出現
在上面的名單表格裡，狀態是「未產生」。**這個很適合報到現場臨時要加人的情境。**

### 方式 C：在網頁上「批次匯入」（貼上，或直接上傳 Excel / CSV 檔案）

「批次匯入」卡片提供兩種輸入方式，結果一樣，都會先預覽再匯入：

- **上傳檔案**：點「📄 上傳 Excel / CSV 檔案」，選本機的 `.xlsx` `.xls` `.csv` 檔案。**一律只讀取
  第一個工作表的第一列當標題**，不支援多工作表選擇——如果檔案裡有好幾個工作表，請先另存成只有一個
  工作表的檔案再上傳。檔案完全在瀏覽器裡解析，不會上傳到任何地方，只有你按下「確認匯入」之後，
  解析出來的資料才會真的寫進試算表。
- **貼上**：從 Excel 或 Google 試算表選取多列多欄、複製，貼到下方文字框。

不管用哪一種，都要按「解析預覽」（上傳檔案會自動幫你按過一次）確認欄位對應正確——如果資料第一列
剛好跟目前類別的欄位名稱一致，會自動辨識為標題列；如果檔案裡的欄位名稱跟類別不完全一樣（例如順序不同
或名稱有出入），會被當成純資料列位置對應，**務必看一下預覽表格再按「確認匯入」**，避免對錯欄。

### 名單表格裡每一列可以做的事

- **勾選框**：左邊第一欄可以勾選特定幾筆，勾了之後「產生名牌」頁籤會多一個「🖨️ 只產生勾選的」按鈕，
  PDF 匯出也會自動只匯出勾選的那幾筆——很適合臨時只要幫一兩個人補印的情況。不勾的話兩個功能都預設
  處理全部名單，行為跟以前一樣。
- **編輯**：打錯字不用整列刪除重建，點編輯會把資料帶回上面的表單，改完按「更新」即可。
- **刪除**：整列移除（無法復原）。
- **重設狀態**：只有已經產生過的列才會出現，點了會把這一列變回「未產生」，方便重新輸出
  （例如背景圖換版之後，想針對某幾個人重新產生）。

## 五、產生名牌

切到「④ 產生名牌」頁籤，選類別後會看到「總名單數 / 已產生 / 未產生」統計。

### 輸出範圍

最上方三個按鈕決定這次要處理哪些名單，**PNG 和 PDF 匯出共用同一個設定**：

- **全部名單**：不管產生狀態，全部處理（預設）。
- **只處理未產生的**：只處理「未產生」的列——加了新名單之後點這個最方便，已產生過的不會被重做。
- **只處理勾選的**：只在「名單管理」有勾選名單時才能點，只處理勾選的那幾筆，適合補印少數幾個人。

右側另有兩個輔助按鈕：
- **🗑️ 清除全部生成紀錄**：把所有列的「產生狀態」清空（例如背景圖或版面大改，需要整批重新產生時），
  操作前會跳出二次確認。
- **📁 開啟 Drive 資料夾**：開啟這個類別的 Drive 輸出資料夾（第一次儲存時自動建立）。

### PNG 圖片

切到「📷 PNG 圖片」頁籤：

- 點「**⬇ 渲染並下載 ZIP**」，瀏覽器會在本機合成所有名牌並打包成 ZIP 直接下載，過程中可以按「**⏹ 取消**」
  中止。
- 勾選「**同時儲存 PNG 至 Google Drive**」：合成完成後會再逐張上傳至 Drive 輸出資料夾（每張一個 PNG
  檔案），適合需要長期存檔或之後個別補印的情境；張數很多時這個步驟會花較長時間。

> ⚠️ 產生過程中請不要關掉分頁，也不要同時有兩個人對同一個類別按產生——目前是用「試算表列號」辨識
> 每一筆名單，如果產生期間有人手動排序或刪除該分頁的列，可能會對錯人。建議「產生名牌」這個動作
> 固定由一個人操作。

### 匯出成 PDF（送印用）

切到「📄 PDF 列印」頁籤，可以把名單重新排版成一份多頁 PDF 直接送印或用印表機批次列印：

- **紙張 / 方向**：A4 / Letter，或選「自訂尺寸」直接輸入寬高（mm）；自訂尺寸時不需要選方向。
- **名牌寬度 / 名牌高度 (mm)**：名牌在紙上的實際格子大小。選好類別後會自動依背景圖比例填入建議值；
  旁邊的 🔒 可以鎖定長寬比，鎖定後改其中一邊另一邊會跟著等比例調整；「**還原原始尺寸**」會恢復到
  背景圖比例算出的原始建議值。**不用自己算一頁能排幾個**，工具會自動塞最多，必要時把名牌轉 90°
  以排進更多個（名牌內容還是正的，只是在紙上方向轉了 90°）。
- **名牌間距 / 頁面邊界**：彼此間隔和四周留白，單位 mm。
- **額外空白名牌張數**：在命名名牌後面附加的空白格數，方便現場備用或手寫補充。

三個動作按鈕：
- **🔍 預覽版面**：用格線圖顯示這一頁能排幾行幾列、是否需要旋轉，確認版面再匯出。
- **📄 匯出命名名牌 PDF**：產生含所有名單的完整 PDF 並下載；完成後這批名單會被標記為已產生。
- **⬇️ 下載空白版型 PDF**：只有背景圖、沒有任何文字的純版型，適合送印刷廠對版或現場手寫用。

勾選「**同時儲存 PDF 至 Google Drive**」：下載的同時也把 PDF 上傳一份到 Drive 輸出資料夾。

> 💡 PDF 裡的名牌解析度是依「每個名牌在紙上的實際大小」自動換算（約 200 dpi），不會直接套用背景圖
> 的原始解析度——這是刻意的，不然名單一多，PDF 檔案會大到瀏覽器處理不動。要最高畫質的單張圖，
> 請用「PNG 圖片」頁籤下載 ZIP 或開啟 Drive 資料夾取得 PNG 原始檔。

## 六、換一場新活動 / 切回舊活動

### 換成新的活動

兩種做法都可以：

**A. 從舊的複製（最快，版面設定會一起帶過去）**
1. 打開舊活動的試算表 → 檔案 → 建立副本。
2. 回到名牌工具「① 活動設定」，先把舊的那份「取消連結」，再把新複製出來的試算表網址貼上、按「連結」。
3. 到「② 版面編輯」為每個類別重新上傳這次活動的背景圖（版面位置設定會保留，如果新背景的長寬比例
   差異很大，再微調文字位置即可）。
4. 到「③ 名單管理」清掉舊名單、貼上新名單（或直接刪除舊分頁重建）。

**B. 從零開始**
1. 「① 活動設定」→「建立新的活動試算表」（不用先取消連結舊的也可以，這樣兩份會同時連結著，
   如果不想同時看到兩份的類別混在一起，記得把舊的「取消連結」）。
2. 照本文件「二、三、四」重新設定一次類別、背景、名單。

兩種方式都不會動到舊活動的試算表和產生過的圖片，舊活動的資料永遠留在它自己的試算表和 Drive 資料夾裡。

### 切回舊的活動

「取消連結」只是讓這個瀏覽器分頁暫時不指向它，**不會刪除任何資料**。「活動設定」頁籤有一個
「最近使用過」清單，會記住最近連結過的幾份試算表（存在瀏覽器的 localStorage，跟前面「連結哪份
試算表」那個只認這一個分頁的暫存不一樣，這個清單**換瀏覽器分頁、甚至關掉分頁重開都還在**），點一下
就能直接接回去，不用重新去找網址貼。

### 不小心關掉分頁怎麼辦

「目前連結哪份試算表」只存在那個分頁自己身上，分頁關掉這個記錄就不見了，但**試算表本身、名單、
產生過的圖片全部都還在 Google Drive 裡**，沒有任何資料真的遺失。復原方式：
1. 重新打開這個工具的網址（開一個新分頁）。
2. 如果那份試算表最近才用過，「最近使用過」清單應該還看得到，點一下就接回來了。
3. 如果清單裡也沒有了（例如清過瀏覽器資料、換了電腦），到 Google Drive 或 Google 試算表首頁的
   「最近使用的項目」找回那份試算表，把網址複製貼到「連結活動試算表」重新連結即可——試算表的網址
   本身就是永久的，只要找得到那份試算表，隨時都能重新連上。

## 七、常見問題

**Q：背景圖片真的沒有大小限制嗎？**
技術上 Apps Script／Drive 可以處理到數十 MB 的檔案，但圖片越大，瀏覽器上傳、合成的時間越久。建議
一般名牌用的圖（就算是 300dpi 印刷品質）控制在 20MB 內都會很順。輸出永遠是照你上傳圖片的原始像素
尺寸畫，不會因為預覽畫面縮小而降低輸出品質。

**Q：中文字型跑掉 / 每台電腦看起來不一樣？**
工具預設會從 Google Fonts 載入「思源黑體 Noto Sans TC」，只要產生名牌時電腦有連網，字型會是統一的，
不會因為用的是哪一台電腦、灌了什麼字體而跑版。

**Q：名字太長字會不會爆出背景外？**
每個文字欄位都有「最大寬度」設定，超過會自動縮小字級，字級縮到一定程度還是放不下時會自動換行（最多
三行）。可以在版面編輯器用真實姓名（尤其是全部名單裡最長的那個）先測試一次。

**Q：一次要產生幾百張會不會逾時？**
不會卡在單次執行的 6 分鐘限制，因為每一張圖是各自獨立送出存檔——但整個瀏覽器分頁跑完全部所需的
時間還是跟總張數與電腦效能成正比，數百張建議預留幾分鐘、期間不要切走分頁。

**Q：不同的名牌類別分散在不同試算表，或都放在同一份，該怎麼處理？**
兩種都支援，而且可以「同時」連結多份試算表：
- **都放在同一份試算表**（跟 `sample-data/` 測試的方式一樣）：一份試算表裡每個類別各自一個分頁，
  只要連結這一份就好，這是最簡單、最推薦的用法，見上面「二、三」的說明。
- **分散在不同試算表**：「活動設定」頁籤可以同時連結好幾份試算表，不用只能連一份，也不用開多個
  瀏覽器分頁。連好之後，「名牌類別」清單會把所有已連結試算表的類別**彙總在一起**，每張類別卡片
  會標明是來自哪一份試算表（超過一份時才會顯示這個標籤，只連一份的話畫面跟以前一樣乾淨）。
  「連結活動試算表」區塊也會反過來列出每一份試算表底下有哪些類別，兩邊互相對得起來。
  - 如果兩份試算表剛好有**同名的類別代碼**（例如都有一個叫「學員」的分頁），工具只會採用先連結的
    那一個，並跳出警告提醒你——這種情況建議把其中一個的類別代碼改掉，兩邊才不會打架。
  - 新增類別、「快速建立範本類別」這些「新增」性質的動作，因為要決定新增到哪一份，連結超過一份時
    會多出一個「要套用到哪一份試算表」的下拉選單，預設選最後連結的那一份。

**Q：可以同時管理很多場不同活動嗎？**
可以。每個瀏覽器分頁自己記住「這個分頁連結了哪些試算表」，重新整理會保留，但不同分頁彼此獨立、
互不影響——開分頁 1 處理活動 A、分頁 2 處理活動 B，兩邊不會互相覆蓋對方的連結清單。

**Q：連結試算表後，「偵測到其他分頁」怎麼沒看到我要的那個分頁？**
兩種可能：這個分頁名稱剛好跟現有類別的類別代碼一樣（已經被當成同一個類別了），或這個分頁就是工具用來
存設定的「設定」分頁本身，這兩種都不會出現在可採用清單裡。

**Q：類別名稱打錯了，或想刪除某個類別，怎麼辦？**
「活動設定」頁籤的每個類別卡片上都有「✏️ 重新命名」「🗑️ 移除」。移除只會拿掉工具裡的登記，
**底下的名單分頁不會被刪除**，資料還在，之後要用「採用既有分頁」隨時可以再接回來；如果要連分頁
資料一起刪掉，需要自己到試算表裡刪除該分頁。

**Q：想直接用試算表本身操作，不透過網頁可以嗎？**
名單本來就可以直接在試算表編輯（見「四、方式 A」）。但背景圖上傳、版面拖曳、實際「合成圖片」這幾步
一定要透過網頁工具，因為合成是在瀏覽器裡用 canvas 完成的。

## 八、之後可以再強化的方向

目前這個版本已經涵蓋你提出的核心需求（背景不限大小、試算表匯入名單、位置可調、網頁/試算表都能新增
並支援增量產生、換活動只要換連結+背景、批次列印用 PDF）。如果之後想繼續加強，比較值得投資的方向
大致依「投報率」排序：

1. **QR Code / 條碼**：報到簽到、場內動線常會用到，可以在版面編輯器加一種「QR code 欄位」，內容可以
   是身分編號或報名系統的連結。
2. **名單搜尋 / 篩選**：人數多時（50+ 筆）捲動找人很費力，加搜尋框可以快速定位。
3. **匯入重複偵測**：匯入名單時檢查是否有重複的姓名或關鍵欄位，避免印出兩張一樣的名牌。
4. **類別版面複製**：新活動沿用舊版面時，目前要重新拖曳設定一次，能直接複製整個類別的版面會省很多時間。
5. **Email 個別寄送**：產生完後直接寄給本人（例如電子入場憑證），可以用 GmailApp 搭配名單裡的 Email 欄位。
6. **權限分層**：目前「執行身分：我」代表任何有網址的人操作起來都是同一個身分，如果未來需要區分
   「誰能改版面設定」「誰只能新增名單」，需要另外設計簡單的密碼或 Google 帳號白名單機制。
7. **多人協作鎖定**：目前用列號辨識名單列，多人同時操作同一類別有極小機率互相干擾（見上方「五」的
   提醒），之後可以改成用一個穩定的唯一 ID 欄位辨識，徹底避免這個問題。
